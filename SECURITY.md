# Security boundary

This package is a reference application authorization mechanism for owned
synthetic tools. It is not a sandbox and has not received an independent security
audit. See `docs/design.md` for the complete boundary and known limitations.

Do not put real secrets in public reports. For a suspected vulnerability, contact
the maintainer at email@lucioduran.com with a minimal synthetic reproduction,
affected revision, expected decision, observed decision and effect. Do not test
against third-party systems. No response-time commitment is made.
